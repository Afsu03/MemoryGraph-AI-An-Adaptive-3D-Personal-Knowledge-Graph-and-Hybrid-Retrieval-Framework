\subsection{Temporal Memory Decay \& Retention Accuracy}
In the 180-day longitudinal simulation, queries targeting active working memory concepts achieved a top-3 retrieval precision of $91.4\%$ under MemoryGraph-AI's dynamic activation model $\mathcal{A}(n, t)$, compared to $61.2\%$ for time-agnostic vector search, demonstrating effective alignment with human cognitive recall patterns.
