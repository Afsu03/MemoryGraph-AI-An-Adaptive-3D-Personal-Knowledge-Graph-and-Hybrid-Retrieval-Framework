\section{Conclusion and Future Work}
\label{sec:conclusion}

In this paper, we presented \textbf{MemoryGraph-AI}, an adaptive framework that transforms unstructured personal knowledge repositories into dynamic 3D personal knowledge graphs grounded in cognitive memory dynamics. By formulating an ACT-R/FSRS-inspired temporal memory-decay model, a topology-constrained 3D parametric UMAP spatialization loss, and a multi-channel hybrid retrieval engine fusing dense vectors, BM25 keywords, personalized graph walks, and temporal gating, MemoryGraph-AI bridges the gap between static note-taking and intelligent retrieval-augmented synthesis. Extensive empirical evaluations demonstrate marked gains in multi-hop retrieval accuracy ($+18.4\%$ MRR@5), generation faithfulness ($+22.1\%$), and reduction in user cognitive load ($-34.7\%$).

Future work will investigate: (1) on-device quantized Small Language Models (SLMs) running locally via WebGPU/WebLLM for private edge entity extraction; (2) multi-user collaborative 3D memory spaces with privacy-preserving subgraph federations; and (3) multimodal memory ingestion extending to audio lectures, video annotations, and handwritten mathematical diagrams.
